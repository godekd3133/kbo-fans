- 작게 다듬었어요: 키보드와 스크린리더로 하단 탭, 일정, 팀 선택을 더 명확하게 조작할 수 있습니다.

- 고쳤어요: 문자중계 갱신 중 다시 불러오기를 요청하면 요청이 빠질 수 있던 문제를 보정했습니다.
- 작게 다듬었어요: 앱으로 돌아온 직후 경기판을 다시 맞출 때 진행 중인 조회를 불필요하게 다시 시작하지 않도록 정리했습니다.

## 0.1.18+86 - 경기 정보와 알림 안정성

- 고쳤어요: 해외에 있거나 자정 무렵 앱을 열어도 오늘 경기, 일정, 순위가 전날 기준으로 보일 수 있던 문제를 줄였습니다.
- 고쳤어요: 경기 시작과 예매 알림 시간이 기기 시간대에 따라 어긋날 수 있던 문제를 보정했습니다.
- 빨라졌어요: 종료 경기의 문자중계, 박스스코어, 라인업을 이어서 볼 때 같은 선수 기록을 더 빠르게 불러옵니다.
- 고쳤어요: 박스스코어 표 형식이 바뀌거나 투수 이닝이 분수 형태로 표시될 때 기록이 비어 보일 수 있던 문제를 보정했습니다.
- 작게 다듬었어요: Live Activity와 경기 알림이 앱을 다시 연 뒤에도 현재 경기 기준을 더 안정적으로 유지합니다.

- 고쳤어요: 앱을 보는 중 원격 푸시를 받으면 앱 안 팝업으로 확인하고, 알림을 눌렀을 때 잘못된 화면으로 가지 않도록 보정했습니다.
- 작게 다듬었어요: 2026 시즌 순위 기본 데이터를 최신 흐름에 맞게 갱신했습니다.

- 작게 다듬었어요: 일정 매치업 보기는 지난 경기를 섞지 않고 오늘 기준 남은 맞대결을 가까운 순서로 보여줍니다.

- 고쳤어요: 라이트모드에서 두산 팀 로고가 어둡게 뭉쳐 보이던 문제와 direct 선수 상세 최근 5경기 표시를 보정했습니다.
- 작게 다듬었어요: 푸시 알림 설정은 항목별 토글 중심으로 정리하고, 화면 이동은 조금 더 여유 있게 보이도록 조정했습니다.

- 작게 다듬었어요: 홈 오늘 경기와 순위는 전체 항목을 바로 보여주고, 뉴스와 경기 상세는 더 담백한 문구와 기록 중심 화면으로 정리했습니다.

## 0.1.8+75 - 라이브 경기 알림과 상세 화면 보강

- 마이팀 경기 알림은 저장된 끄기 설정과 무관하게 경기 시작, 득점, 안타, 홈런, 역전, 라인업, 이닝, 타석 흐름까지 더 빠짐없이 받을 수 있게 정리했습니다.
- iOS 17.2 이상에서는 앱을 열지 않아도 라이브 경기가 시작될 때 Live Activity / Dynamic Island가 자동으로 시작될 수 있게 보강했습니다.
