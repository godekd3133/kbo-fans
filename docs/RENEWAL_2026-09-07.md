## 사용자 결정과 완료 기준

요청: 앱의 기능·구현·기획·디자인 전체를 점검하고 시장 앱과 비교해 개선한다. 사장님이 선택한 중심 가치는 **내 팀 경기의 빠른 확인 + 깊이 있는 기록 분석과 야구 이해**다.

제품 방향: **내 팀의 지금을 바로 보고, 궁금한 기록을 이해하며 다음 경기까지 이어가는 앱**. 기존 Flutter/Riverpod/GoRouter/Dio 앱과 FastAPI 백엔드, KBO 실데이터 계약을 기반으로 구현한다.

완료 기준:

- 모든 제품 영역의 구현/기획 대조와 경쟁 공식자료 비교를 남긴다.

- 확인된 데이터/시즌 계약 결함을 회귀 검증과 함께 수정한다.
- 390×844 실제 앱 화면을 변경 전후 비교하고 좁은 화면/큰 글자/상태별 테스트를 수행한다.
- Flutter 분석·테스트·웹 빌드와 변경 백엔드 테스트를 구분해 기록한다.

## 결과와 연결 문서

19개 제품 영역을 현재 소스와 기획에 대조하고 8개 경쟁 서비스의 공식 자료를 검토했다. 결과는 기존 Flutter 앱·FastAPI 코드에 반영했으며, 별도 화면 모형으로 대체하지 않았다.

- [세부 기능 감사](RENEWAL_FEATURE_AUDIT_2026-09-07.md): IA, 19개 영역, provider/API owner, 변경과 보존 이유, 기획 gap, 후속 검증.

- [앱 명세](APP_SPEC.md), [디자인 기준](FIGMA_PROMPT.md), [제품 기획](PLANNING.md), [작업 이력](WORKLOG.md), [변경 이력](../CHANGELOG.md), [실행 안내](../README.md)를 동기화했다.
