## 1. 앱 네비게이션 구조

### Bottom Tab Navigation (5탭)

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                [화면 콘텐츠 영역]                    │
│                                                     │
├─────────┬─────────┬─────────┬─────────┬────────────┤
│  ⚾ 홈   │  📅 일정 │  📊 순위 │  👥 기록실 │  ⚙️ 설정  │
└─────────┴─────────┴─────────┴─────────┴────────────┘
```

### 화면 흐름도 (Navigation Flow)

```
[온보딩 - 마이팀 선택]
        │
        ▼
[홈: 스코어보드] ──tap 경기 카드──▶ [경기 상세]
        │                              ├── 탭: 스코어
        │                              ├── 탭: 문자중계
        │                              ├── 탭: 박스스코어
        │                              └── 탭: 라인업
        │
[일정] ──tap 날짜──▶ [해당일 경기 목록] ──tap──▶ [경기 상세]
        │
[순위] (단일 화면)
        │
[기록실] ──tap 선수 카드──▶ [선수 상세]
        │
[설정]
   ├── 마이팀 변경
   ├── 알림 설정
   └── 앱 정보
```

│  └───────┘  └───────┘  └───────┘   │
│  ┌───────┐  ┌───────┐  ┌───────┐   │
│  │ 삼성  │  │  NC   │  │ 한화  │   │
│  │ [로고] │  │ [로고] │  │ [로고] │   │
│  └───────┘  └───────┘  └───────┘   │
│  ┌───────┐  ┌───────┐  ┌───────┐   │
│  │ 롯데  │  │  KIA  │  │ 두산  │   │
│  │ [로고] │  │ [로고] │  │ [로고] │   │
│  └───────┘  └───────┘  └───────┘   │
│             ┌───────┐               │
│             │ 키움  │               │

│  │         시작하기              │    │

│                                     │

```

**UI 요소**:
| 요소 | 설명 |
|------|------|
| 팀 로고 그리드 | 10개 팀, 3열 그리드. KBO CDN 엠블럼 이미지 사용 |
| 선택 상태 | 선택 시 팀 컬러 border + 체크 아이콘. 1팀만 선택 가능 |
| 시작하기 버튼 | 팀 선택 시 활성화 (팀 컬러로 변경) |
| 건너뛰기 | 팀 미선택으로 진행. 설정에서 나중에 선택 가능 |

**인터랙션**:
- 팀 탭 → 선택 토글 (이전 선택 해제)
- 시작하기 → AsyncStorage에 `myTeam` 저장 → 홈 화면 이동
- 건너뛰기 → `myTeam = null` → 홈 화면 이동
- 2회차 이후 앱 실행 → 온보딩 스킵, 바로 홈

### 2.2 홈: 오늘의 스코어보드 + 브리프

**목적**: 오늘 전 경기 스코어와 마이팀/리그 요약을 한 화면에서 빠르게 확인

```
┌─────────────────────────────────────┐
│  ⚾ KBO Fans          2026.03.28 🔴  │
├─────────────────────────────────────┤
│                                     │
│  ★ 마이팀 경기                       │
│  ┌─────────────────────────────────┐│
│  │  KT          6    4회초    LG   ││
│  │  [로고]  ●●●●●●         [로고]  ││
│  │          R  H  E  B             ││
│  │  KT      6  9  0  4             ││
│  │  LG      2  3  0  4             ││
│  └─────────────────────────────────┘│
│                                     │
│  ┌─────────────────────────────────┐│
│  │  KIA  3     5회초     0  SSG    ││
│  │  [로고]               [로고]    ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │  롯데 3     5회초     0  삼성   ││
│  │  [로고]               [로고]    ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │  두산 0     4회말     3  NC     ││
│  │  [로고]               [로고]    ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │  키움 0     5회초     3  한화   ││
│  │  [로고]               [로고]    ││
│  └─────────────────────────────────┘│
│                                     │
├─────────┬─────────┬─────────┬───────┤
│  ⚾ 홈  │  📅 일정 │  📊 순위 │ ⚙️설정│
└─────────┴─────────┴─────────┴───────┘
```

**상단 브리프 구성**:
| 요소 | 설명 |
|------|------|
| 마이팀 브리프 | 마이팀 경기 여부, 최근 3경기 흐름, 현재 순위, 다음 행동 CTA |
| 오늘의 야구 | 오늘 경기 수, 라이브 경기 수, 당일 핵심 요약 |
| 빠른 콘텐츠 | 홈런 리더, 오늘의 플레이어, 마이팀 순위 등 짧은 정보 카드 |

**UI 요소**:
| 요소 | 설명 |
|------|------|
| 헤더 | 앱 로고 + 날짜 + 실시간 표시(🔴 빨간 점, 경기 중일 때) |
| 마이팀 브리프 | 마이팀 미선택 시 팀 선택 유도, 선택 시 오늘 경기/다음 경기/최근 흐름/순위 노출 |
| 오늘의 야구 | 경기 수, LIVE 수, 종료 수를 한 줄 요약 카드로 표시 |
| 빠른 콘텐츠 | 리그 리더/오늘의 플레이어/마이팀 순위 등 2~3개 카드형 콘텐츠 |
| 마이팀 경기 카드 | 상단 고정, 확대 카드. 이닝별 스코어(R/H/E/B) 포함 |
| 일반 경기 카드 | 간략 표시: 양팀 로고 + 팀명 + 스코어 + 이닝/상태 |
| 경기 상태 뱃지 | `경기 전` / `1회초` ~ `12회말` / `경기종료` / `우천취소` |

**경기 카드 상태별 표시**:
| 상태 | 표시 방식 |
|------|-----------|
| 경기 전 (Scheduled) | "14:00 예정" + 선발 투수 (있으면) |
| 경기 중 (Live) | 현재 이닝 + 스코어 + 실시간 애니메이션 |
| 경기 종료 (Final) | "경기종료" + 최종 스코어 + 승리투수 |
| 우천취소 | "우천취소" 뱃지 |
| 경기 없음 | 브리프/빠른 콘텐츠는 유지하고, 스코어보드 영역만 빈 상태 카드 표시 |

**인터랙션**:
- Pull-to-refresh → 스코어 수동 새로고침
- 경기 카드 탭 → 경기 상세 화면 이동
- 경기 중일 때 → 30초~1분 자동 갱신 (Adaptive Polling)
- 날짜 탭 → 날짜 피커 열림 → 다른 날짜 스코어보드 조회

**데이터 바인딩**:
```
GET /api/scoreboard?date=2026-03-28
→ 경기 목록 [{gameId, away, home, score, inning, status, ...}]
```

**운영 메모**:
- 서버는 날짜별 scoreboard 응답을 `30초 TTL` 캐시로 보관한다.
- 예정 경기일 때 KBO scoreboard 세부 테이블이 비어도 홈 화면은 fallback payload 로 렌더링한다.
- 예정 경기는 YouTube 검색을 생략하고 KBO 공식 하이라이트 링크만 유지한다.
- 웹 진단 화면은 `health / scoreboard / schedule` 상태를 한 번에 확인한다.

### 2.2.1 기록실

**목적**: 마이팀 선수 현황과 간단 기록을 빠르게 확인

**핵심 구성**:
| 요소 | 설명 |
|------|------|
| 상단 요약 | 엔트리 수 / 엔트리 제외 수 |
| 선수 탭 | `야수` / `투수` 전환 |
| 필터 | `전체` / `엔트리` / `엔트리 제외` |
| 정렬 | 야수는 `이름 / 타율 / OPS`, 투수는 `이름 / ERA / WHIP` |
| 선수 카드 | 이름, 등번호, 포지션, 상태 배지, 간단 기록 |
| 상태 배지 | `정상`, `부상`, `엔트리 제외` |
| 상태 메모 | 부상 이탈, 재활, 컨디션 조정 등 표시 |

**리스트 구조**:
- 팀 엔트리
- 엔트리 제외 / 부상 이탈

**인터랙션**:
- 선수 카드 탭 → 선수 상세 화면 이동

**데이터 바인딩**:
```
GET /api/team/{teamId}/players?season=2026
→ 팀 엔트리 / 말소 / 간단 시즌 지표 / 최근 기록 요약
```

**운영 메모**:
- 기록실 팀 데이터와 팀 스탯은 팀/시즌 기준 `5분 TTL` 캐시를 사용한다.
- 앱은 기록실 로딩 완료 시간을 Dev Console 과 `/api/metrics/client` 로 함께 기록한다.

### 2.3 경기 상세

**목적**: 선택한 경기의 심층 정보 (문자중계, 박스스코어, 라인업)

#### 공통 레이아웃

```
┌─────────────────────────────────────┐
│  ← 뒤로    KT vs LG    잠실 23,750 │
├─────────────────────────────────────┤
│  [KT 로고]     6 : 2     [LG 로고] │
│   KT 위즈     4회초      LG 트윈스  │
├─────────────────────────────────────┤
│  스코어 │ 문자중계 │ 박스스코어│라인업│
├─────────────────────────────────────┤
│                                     │
│        [선택된 탭의 콘텐츠]           │
│                                     │

**상단 고정 영역**:
- 뒤로 버튼 + 경기장명 + 관중수
- 양팀 로고 + 팀명 + 현재 스코어 (큰 폰트)
- 현재 이닝/경기 상태
- 예매 정보 카드: 예매처 / 예매 시작시간 / 예매처 바로가기 / 예매 오픈 알림 토글
- 하이라이트 카드: 유튜브 썸네일 / 영상 제목 / `KBO 하이라이트` / `유튜브 보기` 버튼

#### 2.3.1 탭: 스코어

이닝별 상세 스코어 테이블

```
┌─────────────────────────────────────┐
│ TEAM  1  2  3  4  5  6  7  8  9  R │
├─────────────────────────────────────┤
│ KT    6  0  0  0  -  -  -  -  -  6 │
│ LG    0  0  2  -  -  -  -  -  -  2 │
├─────────────────────────────────────┤
│       H     E     B                 │
│ KT    9     0     4                 │
│ LG    3     0     4                 │
└─────────────────────────────────────┘
```

**UI 요소**:
| 요소 | 설명 |
|------|------|
| 이닝 스코어 테이블 | 가로 스크롤 (9이닝+연장). 현재 이닝 하이라이트 |
| R/H/E/B 요약 | 하단 고정. 안타/실책/볼넷 합계 |
| 현재 이닝 | 컬럼 배경색으로 강조 |
| 미진행 이닝 | `-` 표시 |
| 이닝 상세 보기 | 이닝/점수 셀 탭 시 해당 회차 주요 이벤트 바텀시트 표시 |

#### 2.3.2 탭: 문자중계

투구별 실시간 텍스트 중계

```
┌─────────────────────────────────────┐
│  ┌──── 현재 타석 ────┐              │
│  │ 타자: 이정훈 (좌타)  │             │
│  │ 투수: 이정용 (우투)  │             │
│  │                    │              │
│  │  B: ● ● ● ○       │              │
│  │  S: ● ● ○         │              │
│  │  O: ● ● ○         │              │
│  └────────────────────┘              │
│                                     │
│  ─── 4회초 ───                       │
│                                     │
│  🔴 6번 이강민: 2타점 적시타!         │
│     2루타 (좌중간)                    │
│     S→B→B→S→파울→ 타격              │
│                                     │
│  ⚪ 5번 김민수: 볼넷 출루             │
│     B→S→B→B→B                       │
│                                     │
│  ⚪ 4번 박찬호: 좌익수 플라이 아웃     │
│     S→파울→타격                      │
│                                     │
│  ─── 3회말 ───                       │
│                                     │
│  🔴 3번 오지환: 솔로 홈런! (시즌 1호) │
│     1S 후 타격, 좌측 담장 직격        │
│  ...                                │
└─────────────────────────────────────┘
```

**UI 요소**:
| 요소 | 설명 |
|------|------|
| 현재 타석 카드 | 상단 고정. 타자/투수 정보 + 볼카운트(B/S/O) 실시간 |
| 이닝 구분선 | `─── N회 초/말 ───` 형태 |
| 중계 아이템 | 타석 결과 카드. 역순 정렬 (최신이 위) |
| 이벤트 강조 | 🔴 득점 / ⚾ 홈런 / 🔄 교체 / ⚪ 일반 |
| 투구 시퀀스 | 각 타석의 볼/스트라이크/파울 순서 표시 |

**인터랙션**:
- 자동 스크롤 → 새 중계 추가 시 상단에 삽입 + 부드러운 애니메이션
- 이닝 점프 → 특정 이닝으로 빠르게 이동하는 칩 버튼
- 경기 종료 시 → "경기가 종료되었습니다" 배너

**데이터 바인딩**:
```
GET /api/game/{gameId}/relay
→ {currentAtBat, ballCount, relayItems: [{inning, half, text, event, ...}]}
```

│  ────────────────────────────       │

## 7. 경기 상태 코드

| 상태 | 코드 | 설명 |
|------|------|------|
| 경기 예정 | `SCHEDULED` | 경기 시작 전 |
| 경기 중 | `LIVE` | 진행 중 |
| 경기 종료 | `FINAL` | 정상 종료 |
| 우천취소 | `CANCELLED` | 기상 등 사유로 취소 |
| 서스펜디드 | `SUSPENDED` | 일시 중단 (차후 속행) |

표기 정책:
- 일정 화면 카드 상태 배지는 `경기 전`, `경기 중`, `경기 종료`, `경기 취소`, `서스펜디드`를 사용한다.
- 상세 화면 중앙 보조 문구는 이닝 정보가 있으면 이닝(`4회초`, `연장 10회말` 등)을 우선 노출하고, 없으면 상태 라벨 또는 `18:30 예정`을 사용한다.
- `CANCELLED`는 취소 사유가 미확정일 수 있으므로 앱 기본 문구는 `경기 취소`로 통일한다.
- 연장전은 별도 상태 코드가 아니라 이닝 문자열(`연장 10회초`, `10회말`)로 표현한다.
- `SUSPENDED`는 서스펜디드 경기로 표기하고, 문자중계/상세는 재개 전 기준 안내 문구를 우선 노출한다.
