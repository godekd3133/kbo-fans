# 정보 밀도와 문구 개선 루프

## 사용자 요구와 판단 기준

앱의 모든 흐름에서 신뢰, 편의, 유용성, 시각적 완성도를 높이는 전체 목표를 유지한다. 이번 추가 요구는 설명을 늘리는 대신 사용자가 이미 알 수 있는 내용을 덜어내고, `•`로 정보를 이어 붙이지 않는 것이다. 구분 기호를 다른 기호로 치환하는 것으로 완료를 판단하지 않는다.

1. 기본 화면에는 선택·확인·이동에 필요한 내용이 먼저 보여야 한다.
2. 출처, 예상/공식 여부, 앱 계산, 미제공·조회 실패의 구분은 숨기거나 사실과 다르게 만들지 않는다. 반복 안내는 명시적으로 열 수 있는 정보 동작으로 옮긴다.
3. 시간·구장·팀·역할·기록 같은 메타데이터는 별도 항목과 간격, 줄바꿈으로 표현한다. 긴 원문을 한 줄로 묶지 않는다.
4. 사용자에게 의미와 근거가 불분명한 임의 지수를 공식 기록 옆에 강조하지 않는다.
5. 데이터·내비게이션·알림 계약을 유지하며 확대 글자와 좁은 화면에서도 동작해야 한다.

## 분석과 수정 목표

- 브리핑 첫 화면은 긴 안내와 출처/이동 문구가 반복돼 실제 경기 정보가 아래로 밀렸다. 출처 안내를 정보 버튼으로 옮기고 기본 노출을 주요 소식 3개와 추가 소식 3개까지 제한한다. 더 보기는 명시적 동작이며 필터를 바꾸면 기본 노출로 돌아간다.
- 알림함은 보관 수, 표시 수, 미읽음 수와 최대 보관 개수를 중복 설명했다. 기본 화면에는 미읽음 수와 필터·목록을 두고, 보관 정책은 정보 버튼, 알림 종류는 접힌 상세로 제공한다. 조회 오류는 독립 재시도를 유지한다.
- 온보딩의 선택 미리보기와 혜택 3개는 선택 카드와 제목을 중복했다. 선택 카드의 상태 표시와 고정 진행 동작을 유지하고 반복 내용을 제거한다.
- 기록실의 세부 격차·다음 행동 설명, 선수 상세의 중복 헤더, 순위의 화면 확인 시각은 첫 판단에 기여하지 않았다. 대표 선수·기록·시즌 중심으로 정리한다.
- 박스스코어의 임의 활약/효율 지수는 공식 경기 기록과 함께 읽혀 의미가 모호했다. 주요 타자/투수와 실제 기록을 남긴다. LIVE context에서 의미가 있는 현재 타자·현재 투수 정보는 유지한다.

## 구현과 검증 루프

- `AppMetadataText`는 문자열의 공백으로 구분된 가운데 점과 bullet separator를 항목으로 분리한다. 표기 자체가 의미 있는 `출루·장타`와 소수점 기록은 유지한다. 스크린리더는 각 항목을 쉼표로 구분해 읽는다.
- producer의 응답 문자열 자체와 캐시 키는 바꾸지 않는다. 화면 경계에서 렌더하므로 과거 snapshot과 현재 API 양쪽을 동일하게 표시한다.
- 메타데이터 reflow가 고정 높이의 기록 카드에서 overflow를 일으키는 것을 검사로 확인했다. 첫 카드에는 선수·대표 기록·필수 계산 표지만 남겨 해결했다.
- 박스스코어 확대 글자에서는 태그와 선수 이름을 세로로 유지한다. 지수의 제거 여부가 이름 배치 조건에 영향을 주지 않도록 보정했다.
- 기존 widget 테스트의 기호로 합친 문자열 가정은 각 항목 렌더와 정확한 데이터 identity 검사로 갱신했다. component 테스트로 실제 Text에 separator가 없고 280px/240%에서 overflow가 없음을 확인한다.
- backend current-day fanout 검사 하나가 고정 조회일 2026-10-01을 실제 오늘로 가정해 10월 8일 실행에서 실패했다. 이 테스트만 clock을 10월 1일로 고정해 원래 current-day 동시성 invariant를 검증한다. 운영 시간 정책과 deadline은 변경하지 않는다.

## 근거와 남은 전체 목표

이번 실행의 캡처와 로그는 `artifacts/ux-refinement-2026-10-08/`에 보존한다. 예시 화면은 로컬 fixture 및 명시적 저장 snapshot이며 운영 최신성의 근거가 아니다.

다음 루프는 `app/ios/KboFansWidget/KboFansWidget.swift`와 `app/android/app/src/main/kotlin/com/kbofans/kbo_fans/KboFansScoreWidgetProvider.kt`의 메타데이터 배치, 알림·위젯 진입 이후 복귀, 실제 네이티브 렌더를 대상으로 한다. 문자중계의 중복 점수/볼카운트와 설정의 반복 안내도 같은 전체 목표에서 이어서 점검한다. 현재 정적 소스만으로 해당 표면의 편의성과 아름다움을 완료로 판단하지 않는다. 실기기 알림 실수신과 앱 종료 후 Live Activity 갱신은 별도 증거 층으로 남긴다.
