# 순위표 우선 화면 정리

## 분석과 목표

기존 순위 화면은 표 위에 1위 경쟁·마이팀·연속 흐름 요약을 표시했다. 순위와 승패·연속은 아래 표에 다시 나타났고, 응원팀 미선택 시에는 빈 선택 안내가 공간을 차지했다. 짧은 열 이름을 별도 설명으로 풀어 화면에 상시 노출했다.

상단 요약을 제거해 실제 표를 먼저 보여준다. 응원팀 행의 색·왼쪽 강조선·배지는 유지한다. 승차 설명은 읽기 쉬운 열 이름과 필요할 때 보는 툴팁으로 제공한다.

## 영향 범위·구현

- Flutter 순위 화면: 일반/큰 글자 화면의 중복 요약과 상시 열 설명 제거. ‘차’를 ‘승차’로 바꾸고 ‘1위와의 경기 차’ 툴팁 유지.
- rank, 팀 순서, 승/패/무, 승률, 승차, 연속 값과 my-team 행 강조는 변경하지 않는다. 시즌 이동·refresh·empty/error 상태도 유지한다.
- backend/API/provider/cache·snapshot·푸시·인프라·릴리스 변경 없음.

## 검증

- analyze 무결함, 순위/시즌 이동 관련 14개 테스트 통과. 좁은 폭·큰 글자·my-team 강조·refresh·empty·KST 연도 전환 포함.
- 웹 build 성공. 로컬 reference API 화면에서 중복 요약 제거와 승차 열을 확인했다. 관측 viewport 601x858에서는 10개 팀이 한 화면에 들어온다. 실기기/390px 화면 증거로 주장하지 않는다.
- screenshot API의 빈 반환을 실제 저장 bytes로 확인하고 제외했다. CDP fromSurface capture의 저장 pixels를 다시 열어 정상 표를 확인했다.
- 로컬 fixture 데이터는 공식 과거 시즌 정확성/운영 freshness의 증거가 아니다. 실기기·운영 API·signed release는 not-run. 전체 목표는 진행 중이다.
