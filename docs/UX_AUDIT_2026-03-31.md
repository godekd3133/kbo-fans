# 2026-03-31 웹 UX/UI 점검 메모

## 범위
- Flutter 웹 디버그 세션 실제 실행
- 확인 라우트: `#/onboarding`, `#/home`, `#/schedule`, `#/standings`, `#/settings`
- 보조 확인: `flutter run -d chrome`, `flutter run -d web-server --web-port 7357`
- 실데이터 기준 확인일: `2026-03-31`

## 실행 관찰
- Chrome 디버그 세션에서는 실제 라우트 렌더링이 정상 동작했다.
- 별도 `web-server` 세션은 스플래시(`KBO Fans`, `야구 정보를 준비하는 중입니다`)에 머무는 현상이 있어 웹 배포/프리뷰 경로 점검이 필요하다.
- 홈 화면은 마이팀 미선택 상태에서도 `마이팀 브리프`, `오늘의 야구`, `빠른 콘텐츠`, `전체 경기`가 순서대로 렌더링된다.
- 일정 화면은 `달력으로 보기 / 경기장으로 보기`, `전체 / 마이팀만 / 마이팀 제외` 필터를 제공한다.
- 순위 화면은 단일 테이블 중심 구조이며 스크롤 밀도가 높다.
- 설정 화면은 기능은 명확하지만 설명 텍스트가 부족하다.

## 10개 유저 페르소나와 개선점

### 1. 출근길 라이트 팬
- 목표: 앱을 열고 오늘 경기 있는지 3초 안에 확인
- 현재 관찰: 홈 상단 카드 수가 많아 첫 시선이 분산된다.
- 개선: 홈 첫 화면 상단 1스크린을 `오늘의 야구 + 마이팀 CTA + 첫 경기 카드 1장` 중심으로 더 압축

### 2. 마이팀 코어 팬
- 목표: 내 팀 경기/순위/예매를 제일 먼저 보고 싶음
- 현재 관찰: 마이팀 미선택 상태 메시지는 명확하지만, 선택 유도 버튼 존재감이 약하다.
- 개선: `마이팀 선택하기`를 팀 로고 그리드 미리보기와 함께 더 크게 노출하고 홈 헤더 근처에도 반복 배치

### 3. 경기 직전 예매 사용자
- 목표: 오늘 경기 예매처와 오픈 시간을 빨리 찾기
- 현재 관찰: 홈에서는 예매 정보가 `빠른 콘텐츠`와 일정 카드 하단 보조문구에 퍼져 있다.
- 개선: 홈 카드와 일정 카드에 `예매 오픈`, `예매처`, `D-day/남은 시간`을 배지형으로 더 직접 노출

### 4. 데이터 확인형 팬
- 목표: 순위/기록/상대전력 중심으로 판단
- 현재 관찰: 순위 화면은 정보는 충분하지만 표 헤더 대비 데이터 가독성이 낮다.
- 개선: `내 팀 강조`, `최근 10경기`, `연속`, `홈/원정` 중 일부를 접고 `상세 보기`로 분리해 핵심 열 우선 가독성 확보

### 5. 일정 탐색형 팬
- 목표: 월간 경기 흐름과 원정/홈 패턴 파악
- 현재 관찰: 일정 화면은 기능은 좋지만 상단 컨트롤이 넓고, 날짜 셀의 의미가 약하다.
- 개선: 달력 점 표시에 범례 추가, 선택 날짜 카드 상단 고정, 경기장 보기 전환은 세그먼트보다 탭형이 더 직관적

### 6. 알림 민감 사용자
- 목표: 필요한 알림만 최소한으로 받고 싶음
- 현재 관찰: 설정 토글은 많지만 각 알림이 언제 오는지 설명이 없다.
- 개선: 각 토글 아래 `예시 문구 + 발송 시점`을 1줄 설명으로 추가하고 `마이팀만/전체` 관계를 구조적으로 묶기

### 7. 신규 유입 사용자
- 목표: 앱이 무엇을 잘하는지 바로 이해
- 현재 관찰: 온보딩은 단정하지만 팀 카드가 너무 커서 한 화면에 4개만 강하게 보이고 선택 전 맥락 설명이 약하다.
- 개선: 팀 선택 화면에 `선택 후 무엇이 달라지는지` 2~3개 불릿 추가, 카드 높이 축소로 1스크린에 더 많은 팀 노출

### 8. 고령 사용자
- 목표: 작은 텍스트 없이 핵심 정보만 크게 보고 싶음
- 현재 관찰: 설정/순위/일정의 보조 텍스트가 작고 대비가 약하다.
- 개선: 웹 기준 기본 폰트와 행 높이 1단계 상향, 클릭 영역과 토글 트랙을 더 크게 조정

### 9. 커뮤니티 공유형 팬
- 목표: 경기 상태를 캡처하거나 빠르게 보여주고 싶음
- 현재 관찰: 홈 카드가 정보는 많지만 스코어 중심 카드의 시각적 리듬이 아직 약하다.
- 개선: 경기 카드에 팀 컬러 포인트, 상태 배지 대비, 승부처 정보 한 줄을 추가해 공유 가치 강화

### 10. 장애 상황을 먼저 보는 QA/운영 사용자
- 목표: API 연결/로딩 이상을 빨리 파악
- 현재 관찰: 설정 안쪽 `연결 진단`은 존재하지만 노출 경로가 깊다.
- 개선: 웹에서는 홈 에러 상태나 스플래시 지연 시 `진단 보기` 바로가기를 더 빠르게 노출

## 공통 UX/UI 우선순위

### P1
- 웹 `web-server` 경로가 스플래시에서 멈추는 원인 점검
- 홈 첫 화면 정보량 재정렬: 마이팀/오늘 경기/예매 CTA 우선
- 설정 토글 설명문 추가

### P2
- 순위 테이블 모바일 가독성 개선
- 일정 화면 범례와 선택 상태 강화
- 온보딩 팀 카드 밀도 조정

### P3
- 홈/일정 카드의 공유 친화적 비주얼 강화
- 진단 진입 경로를 홈 상태와 더 가깝게 노출

## 실제 검증 중 확인한 메모
- 홈 라우트에서 `/api/scoreboard`, `/api/schedule`, `/api/standings`, `/api/records/overview`, `/api/metrics/client` 호출이 발생하는 것을 디버그 로그로 확인했다.
- 일정/순위/설정 라우트는 실제 웹 렌더링 스크린샷으로 확인했다.
- 기록실/경기 상세는 코드 구조상 접근 가능하지만 이번 점검에서는 macOS 포커스 경쟁 때문에 안정적인 캡처가 제한됐다.
