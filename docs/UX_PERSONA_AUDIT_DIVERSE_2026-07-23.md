# 다양성 확장 UX·UI·기능 감사 — 2026-07-23

## 결론

기존 20개 사용 맥락을 정보 신뢰 12개, 상태·복구 14개, 극단 화면·접근성 14개로 다시 나눈 40개 페르소나로 확장했다. 이번 감사에서는 화면 완성도뿐 아니라 표시 정보의 의미, 실패 복구, 작은 화면 정보 보존, 보조기술 상태 전달을 같은 우선순위로 검증했다.

즉시 수정 대상으로 판정한 항목은 다음과 같다.

- 앱이 계산한 OPS 기반 참고값을 공식 `wRC+`처럼 표시한 문제
- UTC 또는 추정 예매 시각을 KST 공식 시각처럼 단정한 문제
- 진행·종료·취소 경기를 `남은 경기`에 포함할 수 있던 문제
- 이전 LIVE 데이터를 보존하면서 최신 데이터처럼 보이던 문제
- 알림 권한·등록 결과와 무관하게 푸시 성공을 확정하던 문제
- 콜드 딥링크 실패 시 재시도나 안전한 복귀 경로가 없던 문제
- 취소 경기를 공식 0:0처럼 보이게 하고, 이닝 데이터가 없어도 전부 대시인 표를 노출한 문제
- 280px·240% 글자 크기에서 온보딩, 순위, 박스스코어의 핵심 정보가 잘릴 수 있던 문제
- 캘린더 날짜가 스크린리더에 전체 날짜·선택·마이팀 경기 맥락을 전달하지 않고, 44px보다 작은 터치 영역을 쓰던 문제

## 감사 방법과 증거 경계

- 40개 페르소나를 세 그룹으로 나눠 서로 독립적으로 코드·테스트·현재 웹 화면을 감사한 뒤 결과를 교차 비교했다.
- 현재 release web build를 390×844과 280×720 중심으로 확인하고 홈, 온보딩, 경기 상세, 일정, 순위, 기록, 브리핑, 알림, 설정을 탐색했다.
- 운영 API의 2026-07-23 홈 스코어보드에서 LIVE 경기와 취소 경기를 확인해 상태 표현을 점검했다.
- Flutter widget test는 화면 폭, 240% 글자 크기, semantics, 줄바꿈, 실패 복구를 검증한다. 이 결과는 실제 iOS VoiceOver, Android TalkBack, Switch Control, APNs/FCM 수신을 대신하지 않는다.
- 개선 전·후 웹 캡처는 `artifacts/ux-persona-audit-diverse-2026-07-23/screenshots/`에 같은 감사 회차의 증거로 보존한다.

## 남은 위험과 후속 순서

1. 알림함 read-modify-write를 직렬화하고 background isolate까지 원자성을 보장한다.
2. 온보딩 완료와 푸시 등록 네트워크를 분리한다.
3. 서스펜디드 경기의 polling·팔로우 보존 정책을 upstream game ID 계약과 함께 확정한다.
4. 홈 `/home` aggregate 실패를 실제 빈 상태와 분리하고 scoreboard와 관측 시점을 동기화한다.
5. 읽어야 하는 보조 텍스트와 비활성 컨트롤 색을 분리하고 다크·라이트 고대비 토큰을 자동 검사한다.
6. 700px 이상에서 NavigationRail과 2단 레이아웃을 검토한다.
7. 실제 iOS VoiceOver, Android TalkBack, Switch Control, 240% 글자, 알림 권한 거부, APNs/FCM 수신을 실기기에서 검증한다.

## 검증 기준

- 정적 검증: 변경 Dart/Python format, Flutter analyze `No issues found`, Ruff lint, `git diff --check`
- 기능 검증: Flutter 전체 393개, backend 전체 296개 테스트 통과. 기록 지표, 홈 stale, 경기 상세 복구, 스코어 빈 상태, 박스스코어 리플로우, 일정 KST·남은 경기·캘린더 semantics, 순위·온보딩 회귀를 포함한다.
- 빌드 검증: `USE_BACKEND_API=true`, 운영 `API_BASE_URL`을 사용한 Flutter web release build 성공
- 런타임 검증: 같은 감사 폴더의 개선 후 280×844·390×844 웹 캡처에서 핵심 여정을 확인하고 브라우저 warning/error 0건 확인
