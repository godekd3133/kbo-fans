## Slide 1. KBO Fans

### 주요 캡쳐
- 홈
- 문자중계
- 기록실

### 기능 설명
- KBO 팬이 경기 전, 경기 중, 경기 후에 반복해서 확인하는 기능을 한 앱에 묶는다.
- 홈에서 경기 흐름을 보고, 상세 탭에서 중계, 기록, 라인업을 확인한다.
- 일정, 순위, 기록실, 알림 설정까지 팬 사용 흐름을 이어준다.
- 발표는 실제 구현 화면을 먼저 보여주고 기능 단위로 설명한다.

### 기획한 내용
- 야구 팬이 매번 다른 사이트를 열지 않아도 경기 상태와 기록을 바로 확인하게 만든다.

### 개발한 내용
- Flutter 화면, 라우팅, provider, no-backend 방향을 구현했다.

## Slide 2. 마이팀

### 주요 캡쳐
- 팀 선택
- 홈 반영

### 기능 설명
- 처음 실행 시 응원팀을 선택한다.
- 선택한 팀을 홈의 우선 정보 기준으로 사용한다.
- 설정에서 팀을 다시 바꿀 수 있다.
- 알림과 앱 밖 화면도 마이팀 기준으로 확장할 수 있다.

### 기획한 내용
- 앱을 열자마자 사용자가 관심 있는 팀을 기준으로 경기 정보를 보여준다.

### 개발한 내용
- `OnboardingScreen`, `MyTeamNotifier`, `SharedPreferences` 저장, 설정 진입 라우트를 구현했다.

## Slide 3. 홈

### 주요 캡쳐
- 홈

### 기능 설명
- 오늘 경기 정보를 첫 화면에서 확인한다.
- 마이팀 선택 전에는 팀 선택 CTA를 먼저 보여준다.
- 경기 카드에서 점수, 상태, 구장을 확인한다.
- 카드를 누르면 경기 상세로 이동한다.

### 기획한 내용
- 앱을 켰을 때 오늘 야구 상황을 바로 파악하는 첫 화면으로 설계했다.

### 개발한 내용
- `HomeScreen`, `MyTeamGameCard`, `GameCard`, scoreboard provider, 상세 진입 라우팅을 연결했다.

## Slide 4. 경기 상세 스코어

### 주요 캡쳐
- 상세 스코어
- 스코어 탭

### 기능 설명
- 한 경기의 현재 점수와 상태를 크게 보여준다.
- 이닝별 득점 흐름을 표로 확인한다.
- 안타, 실책, 볼넷 같은 팀 합계를 함께 본다.
- 중계, 박스스코어, 라인업 탭으로 이어진다.

### 기획한 내용
- 경기 하나를 눌렀을 때 스코어 흐름을 가장 먼저 이해하게 만든다.

### 개발한 내용
- `GameDetailScreen`의 스코어 탭, `/game/:gameId` 라우트, 이닝 스코어 UI를 구현했다.

## Slide 7. 라인업

### 주요 캡쳐
- 라인업

### 기능 설명
- 양 팀 선발 구성을 한 화면에서 비교한다.

### 기획한 내용

### 개발한 내용

### 주요 캡쳐
- 알림 항목
- 전달 화면
- 전달 방식

### 기능 설명

## Slide 13. 데이터 처리

### 주요 캡쳐
- 현재 경기
- 과거 기록

### 기능 설명
- 현재 경기와 과거 기록의 데이터 정책을 분리한다.
- 현재 경기는 direct KBO 경로를 우선 사용한다.
- 기록실과 과거 데이터는 generated asset과 snapshot을 활용한다.
- 앱 밖 화면은 별도 service로 동기화한다.

### 기획한 내용
- 라이브성 데이터와 안정적인 기록 데이터를 다르게 처리해 앱을 가볍게 유지한다.

### 개발한 내용
- provider routing, snapshot, WidgetSync, LiveActivity를 준비했다.

## Slide 14. 구현 현황

### 주요 캡쳐
- 홈
- 중계
- 순위

### 기능 설명
- 구현된 화면은 온보딩, 홈, 경기 상세 4탭, 일정, 순위, 기록실, 설정이다.
- 서비스 준비 범위는 예매 알림, push moment, widget sync, live activity다.
- 다음 검증 대상은 실제 기기 push, 위젯, Live Activity, 테스터 배포다.
- 발표에서는 화면으로 확인 가능한 기능과 준비 중인 기능을 구분한다.

### 기획한 내용
- 현재 구현 범위를 과장하지 않고, 화면 구현과 서비스 준비 상태를 나눠 설명한다.

### 개발한 내용
- 앱 화면, provider routing, service skeleton, 문서화 기준을 맞춰 발표 가능한 상태로 정리했다.
