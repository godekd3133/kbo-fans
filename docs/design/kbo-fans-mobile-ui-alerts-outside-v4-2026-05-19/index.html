KBO Fans v4 · Moment Subscription & Surface Strategy

알림은 강도가 아니라
장면 구독이다

v4는 알림 강도 다이얼을 버리고, 사용자가 받을 야구 장면과 전달 표면을 분리한다. Push는 순간 이벤트, Live Activity와 Android Live Update는 사용자가 명시적으로 따라가는 현재 경기, Widget은 개인화 상태판으로 역할을 나눈다.

v3 문제알림 강도는 추상적이다. 사용자는 “득점권을 받을지”, “최종 결과만 받을지”를 고른다.
v4 방향Moment별로 바로 알림, 요약, Live 표면, 끄기를 선택한다.
v3 문제앱 밖 경험이 iOS, Android, Widget, Push의 차이를 충분히 분리하지 못했다.
v4 방향각 OS 표면의 실제 역할과 제한에 맞춰 따로 설계한다.
Moment First알림 단위는 기능이 아니라 야구 장면이다.
Permission In Context벨을 누른 뒤, 예시를 보고 권한을 요청한다.
Follow Is ExplicitLive 표면은 사용자가 경기 따라가기를 눌렀을 때만 시작한다.
Widget Is Not Live위젯은 상태판이고, pitch-by-pitch는 앱/Live 표면이다.
Quiet When Watching사용자가 상세를 보고 있으면 같은 장면 푸시는 줄인다.
