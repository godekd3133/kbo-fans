KBO Fans UI/UX Philosophy V3 · Stadium Control Room

내 팀을 위한
모바일 경기 관제판

v3는 예쁜 다크 앱이 아니라, 경기장 전광판·중계 그래픽·덕아웃 기록지를 모바일에 맞게 압축한 방향이다. 사용자는 앱을 여는 순간 지금, 다음, 나중을 구분하고 필요한 장면만 따라가면 된다.

Service Design사용자 필요에서 시작하고, 기능보다 경기 여정을 설계한다.
Calm Live Data라이브 정보는 빠르게 알리되 사용자의 주의를 과도하게 쓰지 않는다.
Sports Specific야구는 주자, B/S/O, 투수 교체, 타순이 핵심 정보다.
Inclusive색상만으로 의미를 전달하지 않고 조작 영역을 넓게 유지한다.
Atomic System페이지가 아니라 반복 가능한 상태/카드/스코어 모듈로 설계한다.
Content DesignCTA는 기능명이 아니라 사용자가 얻는 결과를 말한다.
Now / Next / Later홈의 정보 우선순위를 시간축으로 정리한다.
Attention Dial알림은 켜고 끄는 것이 아니라 강도를 조절한다.
Field First숫자뿐 아니라 주자와 타석 상황을 시각화한다.
Quiet Outside App위젯은 앱 축소판이 아니라 작은 전광판이다.
Memory Cards팬이 기억할 장면을 경기 후에도 남긴다.
Repeatable StatesLIVE, 예정, 종료, stale, 취소는 같은 언어로 반복한다.
