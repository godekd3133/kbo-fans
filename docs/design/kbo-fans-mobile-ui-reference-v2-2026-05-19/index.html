앱을 열자마자
내 팀 경기 상태가 보이는 구조

레퍼런스 기반으로 홈, 경기 상세, 일정, 알림, 위젯을 다시 정리했다. 목적은 더 화려한 화면이 아니라 3초 안에 현재 상태를 판단하고, 필요할 때만 깊게 들어가게 만드는 것이다.

Material / Android 5개 최상위 탭은 유지하고, 경기 상세 탭은 내부 맥락으로 분리한다.
NN/g / WCAG 상태 가시성, 인식 우선, 44px 조작 영역을 핵심 기준으로 둔다.
Apple Widgets 앱 밖에서는 스코어, 이닝, stale 상태만 빠르게 보이게 한다.

Progressive Depth요약에서 상세, 기록으로 자연스럽게 확장
