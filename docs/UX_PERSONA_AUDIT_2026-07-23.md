# UX 페르소나 감사 및 개선 보고서 — 2026-07-23

## 결론

세 페르소나로 모바일 핵심 여정을 점검한 결과, 첫 사용자 홈 진입을 막는 업데이트 팝업, 홈에서 시작한 마이팀 선택의 잘못된 복귀, 경기 상세의 오래된 데이터 오인, 문자중계 진입 시 상단 잘림, 일정 보기 전환 시 월 헤더 밀림, 작은 화면·키보드·스크린리더 접근성 문제를 확인했다.

이번 작업에서 위 문제를 코드와 회귀 테스트로 개선했다. 웹 release build의 390×844, 320×568, dark/light 화면을 다시 확인했고, 실제 iOS VoiceOver/Android TalkBack과 실제 LIVE 경기 중 네트워크 단절은 별도 실기기 검증이 남아 있다.

## 테스트 페르소나

| 페르소나 | 목표 | 실패에 민감한 지점 |
|---|---|---|
| 처음 쓰는 라이트 팬 | 팀을 고르거나 건너뛰고 오늘 경기까지 빠르게 도달 | 첫 홈을 가리는 팝업, 팀 선택의 복귀 위치, 용어 과밀 |
| 실시간 코어 팬 | 홈에서 진행 경기 중계로 들어가 최신 상태와 상세 기록 확인 | 오래된 점수를 최신처럼 보이는 카피, 중계 첫 요약 잘림, 빈 상태와 오류 혼동 |
| 작은 화면·보조기술 사용자 | 320px 화면, 큰 글자, 키보드, 스크린리더로 같은 기능 수행 | overflow, 작은 터치 영역, 선택/비활성 상태 미전달, 보이지 않는 키보드 포커스 |

| 7. 진행 경기 문자중계 진입 | 코어 팬 | 개선 완료 | `focus=relay`가 sticky 탭 48px을 남겨 첫 요약을 가리지 않음 |

| 9. 경기 상세 후속 갱신 실패 | 코어 팬 | 개선 완료 | 허위 `방금 업데이트` 제거. 성공 시 지연 상태 자동 해제 |

| 11. 일정 월 이동 | 전 페르소나 | 개선 완료 | 이전/다음/오늘 버튼을 44px로 확대하고 tooltip/스크린리더 라벨 제공 |

| 13. 구장별/매치업 API 오류 | 전 페르소나 | 개선 완료 | 빈 일정으로 숨기지 않고 오류와 재시도 표시 |
| 14. 매치업 팀 선택 | 보조기술 | 개선 완료 | 선택 상태 semantics 제공, 중복 팀은 포인터·키보드 모두 비활성 |
| 15. 기록실 탐색 | 코어 팬 | 주의 | 지표 구조는 명확하지만 작은 화면의 정보 밀도가 높음 |
| 16. 뉴스 탐색 | 라이트 팬 | 주의 | 카드 탐색은 가능하나 생성 브리프와 공식 기사 사이의 출처 신뢰 표시는 추가 검토 필요 |
| 17. 설정·테마 변경 | 전 페르소나 | 양호 | dark/light 모두 읽을 수 있고 실제 설정 저장 확인 |
| 18. 무팀 푸시 설정 | 라이트 팬 | 개선 완료 | `10개 켜짐` 대신 `마이팀 미선택`; 직접 팔로우 경기 알림은 별도 동작함을 명시 |
| 19. 하단 5탭 | 보조기술 | 개선 완료 | 비선택 대비 강화, 48px 타깃, 현재 탭 `selected` semantics 제공 |
| 20. 키보드 조작 | 보조기술 | 개선 완료 | 공통 pressable에 Enter/Space, enabled/button semantics, focus outline 추가 |

기존에는 신규 설치의 첫 홈 위에 업데이트 팝업이 떠서 핵심 경기 정보를 가렸다.

### 320px 온보딩

기존 2열 고정 구성은 팀명이 잘리고 하단 행동이 첫 화면 밖으로 밀렸다.

![320px 온보딩 개선 전](../artifacts/ux-persona-audit-2026-07-23/screenshots/24-onboarding-320-overflow-before.png)

개선 후에는 한 열로 전환해 팀명과 선택 상태를 보존하고 세로 스크롤로 이어진다.

![320px 온보딩 개선 후](../artifacts/ux-persona-audit-2026-07-23/screenshots/34-onboarding-320-final.png)

### 일정 필터와 구장별 보기

마이팀 필터 뒤 구장별 보기로 전환하면 월 헤더와 이동 버튼이 viewport 위로 밀리는 경로를 실제 웹에서 재현했다.

![일정 월 헤더 밀림](../artifacts/ux-persona-audit-2026-07-23/screenshots/32-new-tab-myteam-stadium.png)

포커스 정리와 상단 폭 고정 후 같은 경로에서 월 헤더와 세 버튼이 화면 안에 남는다.

![일정 월 헤더 개선 후](../artifacts/ux-persona-audit-2026-07-23/screenshots/33-schedule-myteam-stadium-final.png)

### 문자중계 focus

기존 `focus=relay` 진입은 문자중계 첫 요약 상단을 sticky 탭 아래로 밀어 일부 내용을 가렸다.

![문자중계 focus 개선 전](../artifacts/ux-persona-audit-2026-07-23/screenshots/23-relay-focus-before.png)

개선 후 스크롤 목표가 탭 높이 48px을 남기는지는 390×844 widget geometry 회귀 테스트로 검증했다. 같은 순간의 실제 LIVE 웹 화면은 현재 진행 경기가 없어 재촬영하지 못했다.

## 구현 경계

- 공통 상호작용: button/enabled/selected semantics, Enter/Space, focus outline
- 온보딩: 작은 화면·큰 글자 반응형, 44px 보조 CTA, 출발 화면별 복귀, 신규 설치 버전 기준선
- 홈: 무팀 마이팀 선택 route
- 경기 상세: 갱신 지연 상태·재시도, relay focus 여백
- 일정: 헤더 안정화, 44px 월 버튼, 오류/빈 상태 분리, 선택·비활성 semantics
- 설정: 무팀 알림 상태와 직접 팔로우 경계
- 문서: 앱 명세, 작업 이력, 변경 이력과 본 감사 증거
