# KBO Fans — 나노바나나(Gemini) 디자인 생성 프롬프트

> 용도: 나노바나나(Gemini Nano)에게 페이지별로 복사-붙여넣기하여 Figma 와이어프레임/시안 생성
> 원본: `docs/FIGMA_PROMPT.md`
> Figma 파일: https://www.figma.com/design/VZdeXTfwxJYBxy2xOJrl8c/Kbo-Fans

---

## 사용법

1. 아래 **공통 디자인 시스템**을 먼저 나노바나나에게 전달
2. 이후 **페이지별 프롬프트**를 하나씩 복사해서 전달
3. 한 번에 1~2페이지씩 진행하는 것을 권장 (너무 많으면 품질 저하)

---

## 공통 디자인 시스템 (매번 첫 프롬프트로 전달)

```
너는 모바일 앱 UI 디자이너야. 아래 디자인 시스템을 기반으로 Figma 프레임을 만들어줘.

앱 이름: KBO Fans (KBO 프로야구 실시간 경기 정보 앱)

폰트: Pretendard (한글), SF Pro Display (영문/숫자)
라운드: 카드 16px, 버튼 12px, 입력 8px

컬러:
- 메인 배경: #0F0F0F
- 카드 배경: #1A1A1A

- 구분선: #333333

- KT 위즈: Primary #000000, Secondary #EB1C24

## 페이지 1: 온보딩 — 마이팀 선택

```
KBO Fans 앱의 온보딩 화면을 만들어줘. 최초 실행 시 응원 팀을 선택하는 화면이야.
하단 탭바 없음.

레이아웃 (위→아래):
1. 상단 여백 80px
2. 앱 로고: "⚾ KBO Fans" 중앙, Pretendard Bold 28px, 흰색
3. "응원하는 팀을 선택하세요" 중앙, 16px, #B0B0B0, 위 간격 8px
4. 팀 선택 그리드 (위 간격 40px):
   - 2열 × 5행, 가로 간격 24px, 세로 간격 20px
   - 각 셀: 원형 로고(64×64px) + 팀명(12px, #B0B0B0, 위 8px)
   - 미선택: 3px border #333333
   - 선택: 3px border 팀 Primary 컬러 + 우하단 체크 아이콘
   - 한 번에 1팀만 선택 가능
   - 순서: LG, KT, SSG, 삼성, NC, 한화, 롯데, KIA, 두산, 키움
5. "시작하기" 버튼 (위 간격 40px):
   - 전체 너비(좌우 패딩 24px), 높이 52px, 라운드 12px
   - 미선택: 배경 #333333, 텍스트 #666666 (비활성)
   - 선택: 배경 팀 Primary 컬러, 텍스트 흰색
6. "건너뛰기" (위 간격 16px): 14px, #666666, 중앙

2가지 상태 프레임을 만들어줘: "미선택 상태" / "LG 선택 상태"
```

```
KBO Fans 앱의 화면 간 네비게이션 흐름을 다이어그램으로 만들어줘.
배경 #0F0F0F, 텍스트 흰색, 화면은 #1A1A1A 라운드 사각형, 화살표로 연결.

└─ 재실행 → 홈(스코어보드)

홈 → 홈 화면

순위 → 순위
